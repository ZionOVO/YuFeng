## 3. 切换前检查

| 检查 | 结果与证据 |
|---|---|
| [ ] 客户入口终止业务 TLS；御锋不持业务私钥 | `<必填>` |
| [ ] 入口到边缘为受控网络内 HTTP；防火墙与路由已验证 | `<必填>` |
| [ ] HTTPS 上游证书可由边缘系统信任根验证，或上游使用 HTTP | `<必填>` |
| [ ] 精确可信代理网段与入口直接对端一致 | `<必填>` |
| [ ] 预计峰值不超过每秒 2000 请求和 2048 个在途请求；超出则已重测 | `<必填>` |
| [ ] 发布静态预检归档与 `scripts/delivery-evidence.sh live` 所选入口在线门禁通过 | `<必填：输出位置>` |
| [ ] 当前数据库备份、清单摘要和恢复演练结果已留存 | `<必填>` |
| [ ] 上一版入口配置可在窗口内恢复 | `<必填>` |

## 4. 切换步骤

| 序号 | 动作 | 执行人 | 结果与时间 |
|---:|---|---|---|
| 1 | 核对边缘独立管理口就绪，且单元、姿态、流量键、世代和监听计划符合第 2 节 | `<必填>` | `<必填>` |
| 2 | 经边缘请求上游健康路径，确认状态、`Host`、查询、正文和升级连接符合预期 | `<必填>` | `<必填>` |
| 3 | 反向代理：把选定域名/路由切到边缘；外部授权：加载含外部授权过滤器的新监听器配置 | `<必填>` | `<必填>` |
| 4 | 执行第 5 节验收；任一回退触发条件成立则立即执行第 6 节 | `<必填>` | `<必填>` |

具体配置和校验命令只引用 [`reverse-proxy/`](reverse-proxy/) 或 [`envoy/`](envoy/) 的受控版本，不在变更单粘贴秘密。

## 5. 切换后验收

| 检查 | 期望 | 结果与证据 |
|---|---|---|
| [ ] 普通请求 | 业务状态、头、重复查询和正文保持 | `<必填>` |
| [ ] 已知攻击 | 按当前策略返回 200 或 403，并能关联对应脱敏事件 | `<必填>` |
| [ ] 上游错误 | 4xx/5xx 原样透传；回源失败返回稳定 502 | `<必填>` |
| [ ] 来源边界 | 事件只有部署作用域假名，中台账与日志无原始来源或敏感原文 | `<必填>` |
| [ ] 断网与恢复 | 最后已验证计划和世代继续服务；恢复后补传且不重复 | `<必填>` |
| [ ] 容量 | 延迟、吞吐、内存、盘和在途请求未超过本次批准上限 | `<必填>` |
| [ ] 外部授权（若选） | 200、403、503、超时、部分正文与断连结果符合固定配置 | `<必填或不适用>` |
